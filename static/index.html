Welcome to Prooftext

Prooftext is an advanced keystroke biometrics authentication service that analyzes typing patterns to verify if text was authored by a human or generated artificially.

How It Works

1. Collect Typing Data

Our browser extension captures keystroke patterns including timing, dwell time, and flight time between keystrokes.

2. Analyze Patterns

Advanced machine learning models analyze the biometric signature of your typing to build a unique profile.

3. Verify Authenticity

When you submit new text, we verify it matches your established typing patterns and flag AI-generated content.

Key Features

  • Real-time Analysis: Instant verification response
  • High Accuracy: Multi-factor biometric analysis
  • Privacy-Focused: All data encrypted and securely stored
  • Cross-Device Support: Works on desktop browsers
  • REST API: Easy integration with your applications
  • Session Merging: Support for multiple typing submissions
